# Saraya Yolculuk

Expo ve React Native ile hazırlanmış, Android uyumlu 2D platform/macera oyunu prototipi.

## Geliştirme

```sh
npm run web
```

Expo Go ile Android'de denemek için:

```sh
npm start
```

Telefonda Expo Go ile QR kodu okutun. Android uygulama paketi için Expo/EAS Build kullanılabilir.

## Oyun

- Sol/sağ tuşlarını basılı tutarak ilerleyin; zıplama ve atılma tuşlarını kullanın.
- Altın, mücevher ve can toplayın; saraya ulaşıp sonraki bölümü açın.
- Dükkândan kalıcı hız, zıplama, can, zırh ve yetenek yükseltmeleri satın alın.
- Altın, mücevher, bölüm ilerlemesi, yükseltmeler ve kostümler cihazda AsyncStorage ile saklanır.
