Keep visual refreshes focused on presentation; preserve gameplay mechanics and existing player progress. Gameplay vehicles and objects must read as visibly dimensional 3D at their on-screen size; if a 2D backdrop remains, describe the scene as 2.5D rather than full 3D.

**Why:** The user asked for premium 3D vehicles without changing gameplay or saved progress, and rejected visuals that still read as 2D.

**How to apply:** Make vehicle and object geometry visibly dimensional at gameplay scale. Preserve controls and saved progress. When the illustrated backdrop remains 2D, call the result 2.5D. For menus, shop, map, HUD, and results, change presentation only unless the user asks for gameplay or save changes.
